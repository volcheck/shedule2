# 🏥 График дежурств врачей

Веб-приложение для генерации и управления графиком дежурств врачей с интуитивным интерфейсом drag-and-drop.

## ✨ Возможности

- 📅 **Интерактивный график** — таблица с выбором месяца и года
- 👨‍⚕️ **Управление врачами** — добавление, удаление, цветовое обозначение
- 🖱️ **Drag-and-drop** — перетаскивание врачей на ячейки графика
- 🔄 **Перемещение и замена** — перетаскивание плашек между ячейками с автоматической заменой
- 📊 **Расчёт нагрузки** — автоматический подсчёт часов (день = 8ч, ночь = 16ч)
- 💾 **Экспорт** — сохранение в Word, PDF, копирование в буфер обмена
- 🎨 **Цветовая маркировка** — индивидуальный цвет для каждого врача
- 📱 **Адаптивный дизайн** — работает на десктопе, планшете и мобильных устройствах

## 🛠️ Технологии

### Фронтенд
- **React 18** — UI-библиотека
- **TypeScript** — типизация
- **Vite** — сборщик
- **Tailwind CSS 4** — стилизация
- **@dnd-kit** — drag-and-drop
- **jsPDF** — экспорт в PDF
- **UUID** — генерация уникальных идентификаторов

- **PHP 8.1+** — серверная логика
- **MySQL 8.0+** / **MariaDB 10.6+** — база данных
- **Nginx** / **Apache** — веб-сервер

## 📊 Структура данных

### Врач (Doctor)
```typescript
{
  id: string;              // UUID
  lastName: string;        // Фамилия
  firstName: string;       // Имя
  middleName: string;      // Отчество
  workplace: string;       // Место работы
  color: string;           // HEX-цвет (#RRGGBB)
}
```

### Запись графика (ScheduleEntry)
```typescript
{
  doctorId: string;        // ID врача
  day: number;             // День месяца (1-31)
  column: number;          // Колонка (0-7)
}
```

### Колонки графика
0. Дневная смена — ответственный дежурный
1. Ночная смена — ответственный дежурный
2. Дневная смена — второй дежурный
3. Ночная смена — второй дежурный
4. Дневная смена — третий дежурный
5. Ночная смена — третий дежурный
6. Дневная смена — врач приёмного отделения
7. Ночная смена — врач приёмного отделения

## 🎯 Использование

### Добавление врача
1. Нажмите кнопку **«Добавить»** в списке врачей
2. Заполните ФИО, место работы
3. Выберите цвет-обозначение
4. Нажмите **«Добавить»**

### Назначение дежурства
1. Перетащите врача из списка на нужную ячейку графика
2. Врач будет назначен на эту смену

### Перемещение дежурства
1. Перетащите плашку врача на другую ячейку
2. Если ячейка занята — врачи поменяются местами

### Удаление дежурства
- Наведите на плашку и нажмите **×**
- Или перетащите за пределы таблицы

### Расчёт нагрузки
Таблица нагрузки обновляется автоматически при любом изменении графика:
- Дневная смена = 8 часов
- Ночная смена = 16 часов

### Экспорт графика
- **Копировать** — скопировать таблицу в буфер обмена
- **Word** — сохранить в формате .doc
- **PDF** — сохранить в формате .pdf

## 🔧 Конфигурация

### Хранилище данных

По умолчанию данные хранятся в **localStorage** браузера. Это подходит для:
- Локального использования
- Демо-режима
- Однопользовательского доступа

Для многопользовательского режима настройте PHP-бекенд с MySQL (см. [инструкцию](README_DEPLOY.md#4-вариант-b-полный-стек-фронтенд--php--mysql)).

### Переключение на серверное хранилище

Отредактируйте `src/store.ts`:

```typescript
const API_BASE = '/api';

export async function getDoctors(): Promise<Doctor[]> {
  const res = await fetch(`${API_BASE}/doctors.php`);
  return res.json();
}

export async function addDoctor(doctor: Doctor): Promise<void> {
  await fetch(`${API_BASE}/doctors.php`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(doctor),
  });
}
```
